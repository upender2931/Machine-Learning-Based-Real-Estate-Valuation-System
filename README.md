# 🏠 Smart Real Estate Valuation System

## 📌 Project Overview

The Smart Real Estate Valuation System is a Machine Learning-based web application that predicts property prices based on structural, location, environmental, and market parameters.

The system uses multiple regression models and compares their performance to provide accurate price estimation.

---

## 🚀 Features

- 4-Step User Interface (Streamlit)
- Price Prediction using 4 ML Models
- Cross-Validation for Model Reliability
- Evaluation Metrics:
  - MAE (Mean Absolute Error)
  - MSE (Mean Squared Error)
  - RMSE (Root Mean Squared Error)
  - R² Score
  - Adjusted R²
- Model Comparison Visualization
- Feature Importance Plot
- Correlation Heatmap
- Actual vs Predicted Plot
- Residual Plot
- Handles 30+ Real Estate Parameters

---

## 🧠 Machine Learning Models Used

1. Linear Regression (Ridge)
2. Decision Tree Regressor
3. Random Forest Regressor
4. XGBoost Regressor
